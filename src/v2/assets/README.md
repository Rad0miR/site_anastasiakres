# Картинки версии v2

Чтобы поменять любое изображение — просто положи сюда файл с тем же именем.
**Код трогать не нужно.** Расширение любое: `.webp`, `.jpg`, `.png`, `.avif` —
важно только имя файла.

> Это папка версии `v2` — той, что сейчас открывается на «/». У каждой
> версии свои картинки (`src/v1/assets`, `src/v2/assets`, …), общих файлов
> между версиями нет — поэтому здесь можно менять всё что угодно.

## Фоны

| Файл      | Где виден                          | Рекомендуемый размер |
| --------- | ---------------------------------- | -------------------- |
| `hero`    | фон верхнего экрана                | 1536 × 1024 (3:2)    |
| `finale`  | закат в нижней части сайта         | 2135 × 736 (≈3:1)    |
| `showcase`| большой кадр перед закатом         | ≈1920 × 820 (21:9)   |

`showcase` **пока не приложен**. Секции с ним нет на странице: как только
файл появится в этой папке, широкий кадр с подписью «Small Moments Big
Stories ♡» встанет между стилями и закатом сам.

Текст, логотип и кнопки в фоны не вшиты — это обычные HTML-элементы
поверх картинки. Поэтому фон можно заменить, не трогая надписи.

## Одиннадцать стилей

Порядок и соответствие заданы в `src/v2/data/styles.js`.

| Файл                                | Стиль                        |
| ----------------------------------- | ---------------------------- |
| `style-cinematic`                   | Cinematic                    |
| `style-cartoon`                     | Cartoon                      |
| `style-disney-pixar-dreamworks`     | Disney / Pixar / DreamWorks  |
| `style-vintage-disney`              | Vintage Disney               |
| `style-surrealism`                  | Surrealism                   |
| `style-ultra-realism`               | Ultra Realism                |
| `style-luxury`                      | Luxury                       |
| `style-dark`                        | Dark                         |
| `style-miniature-worlds`            | Miniature Worlds             |
| `style-anime`                       | Anime                        |
| `style-cyberpunk`                   | Cyberpunk                    |

Бери **квадрат** (1254 × 1254 и больше). Один и тот же файл работает
в двух местах:

- в карточке карусели он обрезается в вертикальный прямоугольник по
  верхней трети — **держи главное лицо в верхней части кадра**;
- при нажатии на карточку он раскрывается целиком, квадратом.

## Если файла нет

Ничего не сломается. Карточка стиля останется на месте — тёмная,
с подписью и по-прежнему кликабельная. Раскроется ровный тёплый блок
с названием стиля.

## Вес

Все файлы переведены в `.webp` (80% качества): вместе весят около 1,5 МБ
вместо 25 МБ исходных PNG. Если кладёшь новую картинку — лучше тоже
сохранить её в webp, иначе страница станет заметно тяжелее.
