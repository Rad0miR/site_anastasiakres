# Версия `v2` — сайт Kres AI

Открывается на `/` (пока она актуальная) и всегда на `/v2`.

## Что где

| Файл                        | Что там                                          |
| --------------------------- | ------------------------------------------------ |
| `App.jsx`                   | точка входа версии, порядок блоков страницы       |
| `tokens.js`                 | цвета, шрифты, тени, скругления                   |
| `v2.css`                    | свечения, зерно, стекло — всё, чего нет в Tailwind |
| `components/`               | блоки страницы                                    |
| `data/`                     | тексты, ссылки, списки категорий и стилей         |
| `assets/`                   | картинки (см. README внутри)                      |
| `hooks/`, `lib/`            | карусель, реестр картинок, пресеты анимаций       |

## Почему версия не сломается от новых версий

Всё, что принадлежит версии, начинается с `v2` — и в Tailwind, и в CSS:

| Что                    | Как выглядит                                 |
| ---------------------- | -------------------------------------------- |
| токены                 | `bg-v2-ink`, `text-v2-blush-300`, `ease-v2-silk` |
| брейкпоинт версии      | `v2-xs:` (420px)                              |
| классы из `v2.css`     | `.v2-glass`, `.v2-grain`, `.v2-rail`          |
| переменные CSS         | `--v2-ink`, `--v2-ease-silk`                  |
| глобальные правила     | только внутри `html.v2` — класс ставит `App.jsx` |

Токены попадают в Tailwind из `tokens.js` — `tailwind.config.js` дописывает
к каждому имени префикс версии. Поэтому у `v3` могут быть свои `ink` и
`silk` с любыми значениями: это будут `v3-ink` и `v3-silk`, разные утилиты.

Из общего версия использует только стандартные утилиты Tailwind (отступы,
`sm:`/`lg:`, `text-white/50`) и базовые правила из `src/index.css`.

**Проверка:** удалите из `tailwind.config.js` все версии, кроме `v2` —
ничего не должно измениться. И наоборот: что бы ни появилось в токенах
других версий, на `/v2` это не влияет.

## Шрифты

Plus Jakarta Sans, Cormorant Garamond, Caveat. Подключены в двух местах:
в `index.html` (пока v2 — актуальная версия) и в поле `fonts` записи `v2`
в `src/versions.js` (на случай, когда актуальной станет следующая).
Строка одна и та же; браузер второй раз её не загрузит.
