# Картинки

Чтобы поменять любое изображение — просто положи сюда файл с тем же именем.
**Код трогать не нужно.** Расширение любое: `.webp`, `.jpg`, `.png`, `.avif` —
важно только имя файла.

| Файл           | Где виден                      | Рекомендуемый размер |
| -------------- | ------------------------------ | -------------------- |
| `avatar`       | круглое фото на главном экране | 760 × 760 (квадрат)  |
| `hero-decor`   | натюрморт справа вверху        | ~960 × 800           |
| `instagram`    | карточка Instagram             | 1280 × 853 (3:2)     |
| `instagram-ai` | карточка Instagram AI          | 1280 × 853 (3:2)     |
| `threads`      | карточка Threads               | 1280 × 853 (3:2)     |
| `youtube`      | карточка YouTube               | 1280 × 853 (3:2)     |
| `tiktok`       | карточка TikTok                | 1280 × 853 (3:2)     |
| `pinterest`    | карточка Pinterest             | 1280 × 853 (3:2)     |

## Как кадрируются карточки

Карточка обрезает фотографию по центру: на телефоне — в пропорции 16:10,
на широком экране — примерно 2:1. Поэтому **главный объект держи по центру
по вертикали**, а свободное место оставляй слева: на левую треть ложится
затемнение с названием соцсети и кнопкой.

## Аватар

Файл `avatar` обрезается в круг — бери квадратное фото, лицо окажется в центре.

## Если файла нет

Карточка останется тёмной, но вёрстка не сломается. На месте аватара
появится монограмма «NK».

Хочешь другое имя файла? Поменяй поле `image` в `src/v1/data/links.js`
или `avatar` / `decor` в `src/v1/data/profile.js`.

## Одна папка на обе версии

Картинки намеренно общие: это содержимое, а не оформление. Заменишь файл —
новое фото увидят и `/`, и `/v1`.
