# Картинки

Просто положи файлы сюда с этими именами. Код менять не нужно —
Vite подхватывает их автоматически.

## Фоны карточек

| Файл                | Карточка      | Что на фото                                            |
| ------------------- | ------------- | ------------------------------------------------------ |
| `avatar.webp`       | Главный экран | Твоё фото, квадрат (обрежется в круг). 800×800 px       |
| `youtube.webp`      | YouTube       | Тёмный океан, кит, лунный свет                          |
| `instagram.webp`    | Instagram     | Стильная квартира, путешествия, мягкий свет             |
| `instagram-ai.webp` | Instagram AI  | Футуристическая лаборатория, голограммы, неон           |
| `threads.webp`      | Threads       | Рабочий стол, блокнот, кофе, тёплый свет                |
| `tiktok.webp`       | TikTok        | Городские огни, современная атмосфера                   |
| `pinterest.webp`    | Pinterest     | Moodboard, фотографии, палитры, интерьер                |

**Размеры:** обычные карточки — 1200×1500 px (вертикальные).
YouTube — 2400×1000 px (широкая).

## Мини-стикеры

Папка `stickers/`, формат **PNG с прозрачным фоном**, высота ~1000 px:

| Файл                            | Поза                              |
| ------------------------------- | --------------------------------- |
| `stickers/youtube.png`          | исследует океан с фонарём         |
| `stickers/instagram.png`        | делает селфи                      |
| `stickers/instagram-ai.png`     | работает за ноутбуком             |
| `stickers/threads.png`          | пишет заметки                     |
| `stickers/tiktok.png`           | снимает видео на телефон          |
| `stickers/pinterest.png`        | рассматривает фотографии          |

## Важно

- Можно класть `.webp`, `.jpg`, `.png` или `.avif` — расширение неважно,
  важно **имя файла**.
- Пока файла нет, карточка показывает нарисованный кодом фон и
  векторный стикер-заглушку. Сайт выглядит целым в любом случае.
- Хочешь другое имя файла? Поменяй поля `image` / `sticker`
  в `src/data/links.js`.
