# Версия `v3` — сайт Kres AI

Открывается на `/` (пока она актуальная) и всегда на `/v3`.

## Что где

| Файл                        | Что там                                            |
| --------------------------- | -------------------------------------------------- |
| `App.jsx`                   | точка входа версии, порядок блоков страницы        |
| `tokens.js`                 | цвета, шрифты, тени, скругления                    |
| `v3.css`                    | свечения, зерно, стекло — всё, чего нет в Tailwind  |
| `components/`               | блоки страницы                                     |
| `data/content/`             | весь текст сайта — по файлу на язык                |
| `data/`                     | ссылки, списки категорий и стилей, якоря разделов  |
| `assets/`                   | картинки (см. README внутри)                       |
| `lib/language.jsx`          | выбранный язык: провайдер, `useText`, `useLanguage` |
| `lib/connect.jsx`           | открыта ли форма связи: провайдер и `useConnect`    |
| `hooks/`, `lib/`            | карусель, реестр картинок, пресеты анимаций        |

## Почему версия не сломается от новых версий

Всё, что принадлежит версии, начинается с `v3` — и в Tailwind, и в CSS:

| Что                    | Как выглядит                                 |
| ---------------------- | -------------------------------------------- |
| токены                 | `bg-v3-ink`, `text-v3-blush-300`, `ease-v3-silk` |
| брейкпоинт версии      | `v3-xs:` (420px)                              |
| классы из `v3.css`     | `.v3-glass`, `.v3-grain`, `.v3-rail`          |
| переменные CSS         | `--v3-ink`, `--v3-ease-silk`                  |
| глобальные правила     | только внутри `html.v3` — класс ставит `App.jsx` |

Токены попадают в Tailwind из `tokens.js` — `tailwind.config.js` дописывает
к каждому имени префикс версии. Поэтому у `v4` могут быть свои `ink` и
`silk` с любыми значениями: это будут `v4-ink` и `v4-silk`, разные утилиты.

Из общего версия использует только стандартные утилиты Tailwind (отступы,
`sm:`/`lg:`, `text-white/50`) и базовые правила из `src/index.css`.

**Проверка:** удалите из `tailwind.config.js` все версии, кроме `v3` —
ничего не должно измениться. И наоборот: что бы ни появилось в токенах
других версий, на `/v3` это не влияет.

## Форма связи

Кнопки «Let’s connect ♡» (`components/Header.jsx` и
`components/ConnectInvite.jsx`) открывают окно с формой
(`components/ConnectDialog.jsx`). Открыта она или нет — состояние версии,
живёт в `lib/connect.jsx`.

Заявка уходит POST-запросом на `/api/contact`. Это единственное, что
версия берёт снаружи своей папки, и это не оформление, а сервер: адрес
общий для всех версий, обработчик — в `server/contact.js` в корне
проекта. Токен бота там же, в переменных окружения; на фронт он не
попадает никогда. Подробности — в README проекта, раздел «Форма связи».

## Три языка

Кнопка с глобусом в шапке переключает сайт между 🇺🇦 українською,
🇬🇧 english и 🇩🇪 deutsch.

| Что                          | Где                           |
| ---------------------------- | ----------------------------- |
| текст на языке               | `data/content/en.js`, `uk.js`, `de.js` |
| список языков, язык по умолчанию | `data/content/index.js`   |
| хранение выбора, `<html lang>`   | `lib/language.jsx`        |
| кнопка и список              | `components/LanguageSwitch.jsx` |
| флаги и глобус               | `components/icons.jsx`        |

Дерево у трёх файлов текста одинаковое — образец `en.js`. Компоненты
берут строки хуком `useText()`, поэтому ключ, которого нет в одном из
файлов, просто не покажется на этом языке.

Выбор хранится в `localStorage` под ключом `kres-v3-lang`, по умолчанию
английский. Флаги нарисованы вручную (`flagIcons`), а не взяты эмодзи:
Windows флаговые эмодзи не показывает вовсе.

## Шрифты

Plus Jakarta Sans, Manrope, Cormorant Garamond, Caveat. Подключены в двух
местах: в `index.html` (пока v3 — актуальная версия) и в поле `fonts`
записи `v3` в `src/versions.js` (на случай, когда актуальной станет
следующая). Строка одна и та же; браузер второй раз её не загрузит.

**Manrope — не запасной шрифт, а пара к первому.** Своей кириллицы у Plus
Jakarta Sans нет, поэтому украинский текст без Manrope набирался бы
системным Segoe UI и выбивался бы из дизайна. Латиница всегда достаётся
Jakarta: английский и немецкий выглядят ровно так же, как до появления
переключателя языка.
