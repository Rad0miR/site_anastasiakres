# Первая версия сайта — `/v1`

Заморожена. Открывается по адресу `/v1`, ничего не знает о новом сайте
и не должна меняться при работе над ним.

## Как устроено

`src/main.jsx` смотрит на адрес и рендерит либо `App` (новый сайт), либо
`V1App`. Роутера нет и не нужно: это два независимых приложения, а не две
страницы одного. Переход между ними — обычная ссылка с полной
перезагрузкой, поэтому стили одной версии физически не попадают на другую.

Хостинги уже отдают `index.html` на любой адрес: `netlify.toml`
(`redirect 200`) и `wrangler.toml` (`not_found_handling`). Ничего
донастраивать не надо.

## Почему версия не сломается

Вся вёрстка здесь использует только стандартные утилиты Tailwind. Ни
одного значения из `tailwind.config.js` — вместо них точные величины:

| было (общий токен)  | стало (своё значение)              |
| ------------------- | ---------------------------------- |
| `text-rose-200`     | `text-[#F3BEC3]`                   |
| `bg-night-soft`     | `bg-[#0B080C]`                     |
| `rounded-card`      | `rounded-[24px]`                   |
| `ease-silk`         | `ease-[cubic-bezier(0.16,1,0.3,1)]`|
| `xs:` (420px)       | `min-[420px]:`                     |
| `text-white/85`     | `text-white/[0.85]`                |
| `font-display`      | `.v1-display` из `v1.css`          |
| `shadow-card`       | `.v1-shadow-card` из `v1.css`      |

Всё оформление — в `v1.css`. Глобальные правила (фон, шрифт, выделение,
скроллбар) ограничены классом `v1` на `<html>`, который выставляет сам
`V1App`. Имена классов и keyframes начинаются с `v1-`, поэтому совпасть
с новым дизайном не могут.

**Проверка:** обнулите `theme.extend` в `tailwind.config.js` — `/v1`
должен выглядеть точно так же.

## Что всё-таки остаётся общим

Три вещи, намеренно:

1. **Картинки** — `src/assets/images/`. Это содержимое, а не оформление:
   если Настя заменит фото, логично, что обе версии его увидят.
2. **Шрифты** — подключены в `index.html`. Версии нужны Inter, Playfair
   Display и Marck Script; там стоит комментарий об этом.
3. **Стандартные брейкпоинты Tailwind** — `sm` 640, `lg` 1024, `2xl` 1536.
   Они переживут любые правки внутри `theme.extend`; сломать их можно,
   только переопределив `screens` **вне** `extend`.

Данные (`data/links.js`, `data/profile.js`) намеренно скопированы сюда:
у нового сайта наверняка будет другая структура полей, и первая версия не
должна от неё зависеть. Ссылки на соцсети правятся в двух местах — это
осознанная плата за независимость.
