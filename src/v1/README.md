# Первая версия сайта — `/v1`

Заморожена. Открывается по адресу `/v1`, ничего не знает об остальных
версиях и не должна меняться при работе над ними.

## Как устроено

`src/main.jsx` смотрит на адрес и рендерит ту версию, которой этот адрес
принадлежит; список версий — в `src/versions.js`. Роутера нет и не нужно:
это независимые приложения, а не страницы одного. Переход между ними —
обычная ссылка с полной перезагрузкой, поэтому стили одной версии
физически не попадают на другую.

Код версии грузится отдельным файлом и только по своему адресу: на `/`
он не скачивается вовсе.

Хостинги уже отдают `index.html` на любой адрес: `netlify.toml`
(`redirect 200`) и `wrangler.toml` (`not_found_handling`). Ничего
донастраивать не надо.

## Почему версия не сломается

Вся вёрстка здесь использует только стандартные утилиты Tailwind. Ни
одного значения из `tailwind.config.js` — вместо них точные величины:

| было (общий токен)  | стало (своё значение)              |
| ------------------- | ---------------------------------- |
| `text-rose-200`     | `text-[#F3BEC3]`                   |
| `bg-night-soft`     | `bg-[#0B080C]`                     |
| `rounded-card`      | `rounded-[24px]`                   |
| `ease-silk`         | `ease-[cubic-bezier(0.16,1,0.3,1)]`|
| `xs:` (420px)       | `min-[420px]:`                     |
| `text-white/85`     | `text-white/[0.85]`                |
| `font-display`      | `.v1-display` из `v1.css`          |
| `shadow-card`       | `.v1-shadow-card` из `v1.css`      |

Всё оформление — в `v1.css`. Глобальные правила (фон, шрифт, выделение,
скроллбар) ограничены классом `v1` на `<html>`, который выставляет сам
`App.jsx`. Имена классов и keyframes начинаются с `v1-`, поэтому совпасть
с чужим дизайном не могут.

**Проверка:** обнулите `theme.extend` в `tailwind.config.js` — `/v1`
должен выглядеть точно так же.

Версии, начиная со второй, держат токены у себя (`src/v2/tokens.js`) и
пишут их в Tailwind с префиксом — `bg-v2-ink`. Это то же самое правило
другим способом; переделывать `/v1` под него не нужно.

## Что всё-таки остаётся общим

Две вещи, намеренно:

1. **Базовые правила** — `src/index.css`: поведение браузера и
   `prefers-reduced-motion`. Ничего оформительского там нет.
2. **Стандартные брейкпоинты Tailwind** — `sm` 640, `lg` 1024, `2xl` 1536.
   Они переживут любые правки внутри `theme.extend`; сломать их можно,
   только переопределив `screens` **вне** `extend`.

Своё у версии всё остальное: вёрстка, оформление, картинки (`assets/`,
раньше они лежали в общей папке) и шрифты — Inter, Playfair Display и
Marck Script, они перечислены в поле `fonts` записи `v1`
в `src/versions.js` и подключаются, только когда открыли `/v1`.

Данные (`data/links.js`, `data/profile.js`) намеренно свои: у следующих
версий другая структура полей, и первая версия не должна от неё зависеть.
Ссылки на соцсети правятся в каждой версии отдельно — это осознанная
плата за независимость.
