# Kres AI

Персональный сайт-портфолио AI-креатора Kres AI.
React + Vite + Tailwind CSS + Framer Motion.

## Две версии сайта

В проекте живут два независимых сайта:

| Адрес | Что это                   | Код                          |
| ----- | ------------------------- | ---------------------------- |
| `/`   | Kres AI — актуальный сайт | `src/App.jsx` + `src/components/` |
| `/v1` | первая версия, заморожена | `src/v1/`                    |

Версия выбирается по адресу в `src/main.jsx` (правило — в `src/lib/version.js`).
Роутер не нужен: это не страницы одного приложения, а два разных приложения,
и переход между ними — обычная ссылка с полной перезагрузкой.

Первая версия ничего не берёт из `tailwind.config.js` и `src/index.css` — все её
цвета, шрифты и тени лежат в `src/v1/v1.css`, а картинки — в отдельной папке.
Поэтому новый дизайн можно менять как угодно, `/v1` от этого не изменится.
Подробности: [`src/v1/README.md`](src/v1/README.md).

Общий у версий только `index.html`: заголовок вкладки, meta-описание и подключение
шрифтов там одни на обе. Сейчас там указан новый сайт.

## Структура главной страницы

Один длинный экран, порядок блоков задан ТЗ:

```
Hero  →  Social  →  Content Types  →  Content Styles  →  Финальный визуал  →  Footer
```

| Блок              | Компонент                        | Что внутри                                      |
| ----------------- | -------------------------------- | ----------------------------------------------- |
| Hero              | `components/Hero.jsx`            | фон-фотография, поверх — HTML-текст и кнопка     |
| Social            | `components/SocialRow.jsx`       | 6 площадок в одну строку, на узком — карусель    |
| Content Types     | `components/ContentTypes.jsx`    | 11 категорий: только текст и контурные значки    |
| Content Styles    | `components/ContentStyles.jsx`   | 11 карточек-кнопок + раскрытие картинки          |
| Большой визуал    | `components/Showcase.jsx`        | слот; рисуется, только если есть файл `showcase` |
| Финальная картинка| `components/Finale.jsx`          | закат и «A BRIGHTER TOMORROW»                    |
| Footer            | `components/Footer.jsx`          | логотип, копирайт, фраза справа                  |

### Как работает нажатие на стиль

Карточка стиля — это `<button>`, а не ссылка. Нажатие не открывает ни новый
адрес, ни окно поверх сайта: между каруселью и нижней частью страницы
раскрывается панель с выбранной картинкой, и всё, что ниже, съезжает вниз.
Повторное нажатие на ту же карточку закрывает панель.

Какой стиль сейчас раскрыт — единственное состояние на весь сайт. Оно живёт
в `src/App.jsx`, потому что нужно двоим: карусели и нижним секциям
(`LayerBelow` там же добавляет им доводочный ход, чтобы сдвиг читался как
движение, а не как перерисовка).

## Запуск

Нужен [Node.js 20+](https://nodejs.org).

```bash
npm install
```

```bash
npm run dev
```

Сайт откроется на `http://localhost:5173`, первая версия — на `/v1`.

Сборка в папку `dist`:

```bash
npm run build
```

## Картинки

Подключаются по имени файла, без импортов в коде: положил `hero.webp`
в `src/assets/kres/` — сайт сразу его показывает. Расширение любое.
Подробности: [`src/assets/kres/README.md`](src/assets/kres/README.md).

Одного файла пока нет — `showcase` (широкий кадр между стилями и закатом).
Секция без него просто не рисуется; появится файл — встанет на место сама.

## Раскладка

Мобильная версия — не уменьшенная десктопная: composition собирается заново.

- **Телефон** — герой во весь экран, текст в нижней трети над затемнением;
  соцсети и стили не переносятся на вторую строку, а листаются вбок
  (полоса прокрутки скрыта); категории в две колонки.
- **Планшет (от 768px)** — все шесть соцсетей помещаются в строку,
  категории в четыре колонки, стили по-прежнему листаются.
- **Десктоп (от 1280px)** — все 11 карточек стилей видны разом,
  категории в шесть колонок, соцсети — иконка слева, подпись справа.

## Деплой

### Netlify

Всё уже настроено в `netlify.toml`. Подключи репозиторий — Netlify сам
подставит команду и папку. Либо вручную:

- Build command: `npm run build`
- Publish directory: `dist`

### Cloudflare Pages

- Framework preset: **Vite**
- Build command: `npm run build`
- Build output directory: `dist`
- Environment variable: `NODE_VERSION` = `20`

Заголовки кэширования лежат в `public/_headers` — работают на обеих платформах.

Адрес `/v1` работает без дополнительных настроек: обе платформы уже отдают
`index.html` на любой путь — `netlify.toml` (redirect 200) и `wrangler.toml`
(`not_found_handling`).

## Особенности

- Уважает `prefers-reduced-motion` — движение гасится и в CSS, и в Framer Motion.
- Картинки переведены в `.webp`: все 13 весят около 1,5 МБ вместо 25 МБ исходных
  PNG. Ниже первого экрана они грузятся лениво.
- Внешние ссылки открываются с `rel="noopener noreferrer"`.
- Шрифты грузятся с Google Fonts, есть системный фолбэк:
  Plus Jakarta Sans, Cormorant Garamond и Caveat — новому сайту,
  Inter, Playfair Display и Marck Script — версии `/v1`.
